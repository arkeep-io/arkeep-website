# arkeep.io v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the arkeep.io marketing homepage (three working interactive pieces, light and dark) and the Starlight docs skeleton under `/docs/`, in one Astro project.

**Architecture:**
- Astro 7.3 renders the marketing pages from `src/pages/`.
- Starlight 0.42 renders docs from `src/content/docs/docs/**`, so every docs route starts with `/docs/`.
- One token file (`src/styles/tokens.css`, from `DESIGN.md`) feeds both: the marketing layout imports it directly, Starlight through `customCss` plus a `--sl-*` mapping.
- Interactive pieces are vanilla TypeScript in `<script>` tags. Their logic lives in pure modules under `src/lib/`, unit-tested with Vitest.
- Pages are checked end-to-end with Playwright against `astro preview`.

**Tech Stack:** Astro 7.3.8, @astrojs/starlight 0.42.6, @astrojs/sitemap, @fontsource/be-vietnam-pro, @fontsource/jetbrains-mono, Vitest, @playwright/test, Node 24, pnpm.

**Spec:** `docs/specs/2026-10-14-site-v1-design.md` (read it first; this plan argues from it).

## Global Constraints

- Everything is in English: copy, routes, code, comments. No Italian anywhere.
- Marketing routes have no prefix (`/`). Every docs route starts with `/docs/`.
- Tokens only: components never inline hex. Light values on `:root`, dark on `:root[data-theme='dark']`, plus a `prefers-color-scheme: dark` block on `:root:not([data-theme='light'])` for no-JS.
- Theme state is shared with Starlight: localStorage key `starlight-theme` (`'light' | 'dark' | ''`), attribute `data-theme` on `<html>`.
- Fonts are self-hosted, latin + latin-ext only. Be Vietnam Pro 400/500/600, JetBrains Mono 400. No Google Fonts, no CDN.
- taste-skill house rules apply outside `data-ui` roots:
  - Headlines are two lines or fewer at 1440, 768 and 390 px.
  - No eyebrows, pill badges, gradients, shadows at rest, glass or backdrop blur, thin rules, index numbering (01/02), icon-topped card rows, or styled accent words.
  - Monospace appears only in real `<pre>`/`<code>`.
  - Running text is 16px or larger in full ink. Nothing smaller than 13px.
- Inside `data-ui` roots (product fragments): product conventions apply (1px control borders, 6px radius, small type 13–15px).
- One button shape and one radius on the page: `--radius-md` (6px), the product radius.
- Motion uses transform and opacity only. Every move has a `prefers-reduced-motion` fallback, and content is never hidden if JS fails.
- Contrast is at least 4.5:1 for text. Orange text on the light canvas uses `--primary` (#c94700), never `--brand` (#f66921).
- No real personal data in screenshots. The demo admin is "Alex Rivera" (`alex@example.com`).
- Claude does not run `git commit`. Each task ends with the exact `git add` list and a Conventional Commit message for the user.
- Website repo is `arkeep-website/` (run all commands there unless stated). Product repo is `../arkeep` (read-only, except for running it for screenshots).

## Review Focus

1. **Theme set on one half, page opened on the other.** A visitor picks dark on `/`, then opens `/docs/` (and the reverse). Expected: same theme, no flash. Owner: Task 3, e2e `theme carries across halves`.
2. **Interactive pieces used out of order or repeatedly.** Restore before any break, break twice, run backup while a break is active, run twice. Expected: buttons disabled when not meaningful, the page is never left without its content. Owner: Task 5, e2e `hero fragment survives out-of-order use`.
3. **Retention controls at extremes.** All zero (retention off) keeps everything; very large numbers keep everything without errors; non-numeric input is clamped to 0–999. Owner: Task 6, unit tests `applyRetention` + `clampKeep`.
4. **No JavaScript.** Hero, showcase and how-it-works must show complete, meaningful static content. Owner: Tasks 5–7, e2e `no-js renders static fragments` (one test, context with `javaScriptEnabled: false`).
5. **GitHub API unavailable at build** (rate limit, offline). The build must still succeed and the footer must show a link to all releases. Owner: Task 2, unit tests for `getLatestRelease`.

`scripts/check-links.mjs`:

```js
#!/usr/bin/env node
// Finds internal links in a built site that point at nothing.
import { readdir, readFile, stat } from 'node:fs/promises';
import { join, relative } from 'node:path';
import { fileURLToPath } from 'node:url';

async function htmlFiles(dir) {
  const out = [];
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    const full = join(dir, entry.name);
    if (entry.isDirectory()) out.push(...(await htmlFiles(full)));
    else if (entry.name.endsWith('.html')) out.push(full);
  }
  return out;
}

async function exists(path) {
  try {
    return (await stat(path)).isFile();
  } catch {
    return false;
  }
}

async function resolves(distDir, href) {
  const path = decodeURI(href.split(/[?#]/)[0]);
  if (path.endsWith('/')) return exists(join(distDir, path, 'index.html'));
  return (await exists(join(distDir, path))) || (await exists(join(distDir, path, 'index.html'))) || exists(join(distDir, `${path}.html`));
}

export async function findBrokenLinks(distDir) {
  const broken = [];
  const attr = /\s(?:href|src)="([^"]+)"/g;
  for (const file of (await htmlFiles(distDir)).sort()) {
    const html = await readFile(file, 'utf8');
    for (const [, href] of html.matchAll(attr)) {
      if (!href.startsWith('/') || href.startsWith('//')) continue;
      if (!(await resolves(distDir, href))) broken.push({ page: relative(distDir, file), href });
    }
  }
  return broken;
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const dir = process.argv[2] ?? 'dist';
  const broken = await findBrokenLinks(dir);
  for (const b of broken) console.log(`${b.page}: ${b.href}`);
  console.log(broken.length === 0 ? 'No broken internal links.' : `${broken.length} broken internal link(s).`);
  process.exit(broken.length === 0 ? 0 : 1);
}
```

- [ ] **Step 3: Implement `src/lib/release.ts`**

```ts
export interface Release {
  tag: string;
  date: string;
  url: string;
}

const LATEST = 'https://api.github.com/repos/arkeep-io/arkeep/releases/latest';

// Called at build time; any failure (offline, rate limit, odd payload) yields null
// so the footer falls back to a plain "all releases" link instead of breaking the build.
export async function getLatestRelease(fetchFn: typeof fetch = fetch): Promise<Release | null> {
  try {
    const res = await fetchFn(LATEST, { headers: { Accept: 'application/vnd.github+json' } });
    if (!res.ok) return null;
    const data = await res.json();
    if (typeof data?.tag_name !== 'string' || typeof data?.published_at !== 'string' || typeof data?.html_url !== 'string') {
      return null;
    }
    return { tag: data.tag_name, date: data.published_at.slice(0, 10), url: data.html_url };
  } catch {
    return null;
  }
}
```

- [ ] **Step 3: Implement `src/lib/snapshot.ts`**

```ts
export interface SourceFile {
  path: string;
  bytes: number;
}

export function formatBytes(n: number): string {
  if (n < 1024) return `${n} B`;
  if (n < 1024 * 1024) return `${(n / 1024).toFixed(1)} KiB`;
  return `${(n / (1024 * 1024)).toFixed(1)} MiB`;
}

// Restic shows the first 8 hex chars of a SHA-256 snapshot id; we hash what we "backed up".
export async function snapshotId(parts: string[]): Promise<string> {
  const data = new TextEncoder().encode(parts.join('\u0000'));
  const digest = new Uint8Array(await crypto.subtle.digest('SHA-256', data));
  return Array.from(digest.slice(0, 4), (b) => b.toString(16).padStart(2, '0')).join('');
}

const pad = (n: number) => String(n).padStart(5, ' ');

export function buildLog(files: SourceFile[], id: string, destinations: string[]): string[] {
  const total = files.reduce((sum, f) => sum + f.bytes, 0);
  const lines: string[] = [];
  for (const dest of destinations) {
    lines.push(`[${dest}] open repository`);
    lines.push('using parent snapshot none');
    for (const f of files) lines.push(`  ${f.path}  ${formatBytes(f.bytes)}`);
    lines.push(`Files:       ${pad(files.length)} new, ${pad(0)} changed, ${pad(0)} unmodified`);
    lines.push(`Added to the repository: ${formatBytes(total)}`);
    lines.push(`snapshot ${id} saved`);
  }
  return lines;
}
```

The `Files:` line matches restic's layout: 11 spaces before a single-digit count, numbers right-aligned in 5 columns.

```ts
export interface RetentionPolicy {
  last: number;
  hourly: number;
  daily: number;
  weekly: number;
  monthly: number;
  yearly: number;
}

export function isoWeek(d: Date): number {
  const t = new Date(Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate()));
  const day = t.getUTCDay() || 7;
  t.setUTCDate(t.getUTCDate() + 4 - day); // Thursday of this week decides the ISO year
  const yearStart = Date.UTC(t.getUTCFullYear(), 0, 1);
  const week = Math.ceil(((t.getTime() - yearStart) / 86_400_000 + 1) / 7);
  return t.getUTCFullYear() * 100 + week;
}

export function timeline(end: Date, days: number, everyHours: number): Date[] {
  const count = Math.floor((days * 24) / everyHours);
  return Array.from({ length: count }, (_, i) => new Date(end.getTime() - (count - 1 - i) * everyHours * 3_600_000));
}

export function clampKeep(v: unknown): number {
  const n = Math.trunc(Number(v));
  if (!Number.isFinite(n)) return 0;
  return Math.min(999, Math.max(0, n));
}

type Bucket = { count: number; key: (d: Date, nr: number) => number; last: number | null };

// Mirrors restic's ApplyPolicy: newest first; a snapshot is kept when it opens a new bucket
// for any rule that still has budget. All-zero policy keeps everything.
export function applyRetention(times: Date[], p: RetentionPolicy): boolean[] {
  const keep = times.map(() => false);
  if (Object.values(p).every((n) => n === 0)) return keep.map(() => true);
  const buckets: Bucket[] = [
    { count: p.last, key: (_d, nr) => nr, last: null },
    { count: p.hourly, key: (d) => d.getUTCFullYear() * 1e6 + (d.getUTCMonth() + 1) * 1e4 + d.getUTCDate() * 100 + d.getUTCHours(), last: null },
    { count: p.daily, key: (d) => d.getUTCFullYear() * 1e4 + (d.getUTCMonth() + 1) * 100 + d.getUTCDate(), last: null },
    { count: p.weekly, key: (d) => isoWeek(d), last: null },
    { count: p.monthly, key: (d) => d.getUTCFullYear() * 100 + d.getUTCMonth() + 1, last: null },
    { count: p.yearly, key: (d) => d.getUTCFullYear(), last: null },
  ];
  const order = times.map((d, i) => [d, i] as const).sort((a, b) => b[0].getTime() - a[0].getTime());
  order.forEach(([d, i], nr) => {
    for (const b of buckets) {
      if (b.count <= 0) continue;
      const k = b.key(d, nr);
      if (k !== b.last) {
        keep[i] = true;
        b.last = k;
        b.count--;
      }
    }
  });
  return keep;
}

export const DESTINATION_PRESETS = {
  nas: { label: 'NAS (local)', policy: { last: 4, hourly: 0, daily: 7, weekly: 4, monthly: 0, yearly: 0 } },
  b2: { label: 'Backblaze B2', policy: { last: 0, hourly: 0, daily: 14, weekly: 0, monthly: 0, yearly: 0 } },
  sftp: { label: 'SFTP offsite', policy: { last: 1, hourly: 0, daily: 0, weekly: 4, monthly: 0, yearly: 0 } },
} satisfies Record<string, { label: string; policy: RetentionPolicy }>;
```

```ts
import { applyRetention, clampKeep, DESTINATION_PRESETS, timeline, type RetentionPolicy } from '../lib/retention';

const root = document.querySelector<HTMLElement>('[data-retention]');
if (root) {
  const END = new Date('2026-10-14T18:00:00Z');
  const times = timeline(END, 30, 6);
  const dots = [...root.querySelectorAll<HTMLLIElement>('.dots li')]; // rendered oldest → newest by index via data-i
  const count = root.querySelector<HTMLElement>('[data-retention-count]')!;
  const inputs = Object.fromEntries(
    [...root.querySelectorAll<HTMLInputElement>('input[type="number"]')].map((i) => [i.name, i]),
  ) as Record<keyof RetentionPolicy, HTMLInputElement>;
  const policies = Object.fromEntries(Object.entries(DESTINATION_PRESETS).map(([k, v]) => [k, { ...v.policy }])) as Record<string, RetentionPolicy>;
  let current = 'nas';

  function render() {
    const keep = applyRetention(times, policies[current]);
    for (const li of dots) {
      const i = Number(li.dataset.i);
      li.classList.toggle('kept', keep[i]);
      li.querySelector('.visually-hidden')!.textContent = keep[i] ? 'kept' : 'forgotten';
    }
    const n = keep.filter(Boolean).length;
    count.textContent = `Keeps ${n} of ${times.length} snapshots`;
  }

  function load() {
    for (const [k, input] of Object.entries(inputs)) input.value = String(policies[current][k as keyof RetentionPolicy]);
    render();
  }

  for (const [k, input] of Object.entries(inputs)) {
    input.addEventListener('input', () => {
      policies[current][k as keyof RetentionPolicy] = clampKeep(input.value);
      render();
    });
    input.addEventListener('change', () => { input.value = String(policies[current][k as keyof RetentionPolicy]); });
  }
  for (const btn of root.querySelectorAll<HTMLButtonElement>('[data-step]')) {
    btn.addEventListener('click', () => {
      const key = btn.dataset.key as keyof RetentionPolicy;
      policies[current][key] = clampKeep(policies[current][key] + Number(btn.dataset.step));
      inputs[key].value = String(policies[current][key]);
      render();
    });
  }
  for (const radio of root.querySelectorAll<HTMLButtonElement>('[role="radio"]')) {
    radio.addEventListener('click', () => {
      current = radio.dataset.dest!;
      for (const r of root.querySelectorAll('[role="radio"]')) r.setAttribute('aria-checked', String(r === radio));
      load();
    });
  }
}
```

```ts
const list = document.querySelector<HTMLElement>('#roadmap [role="tablist"]');
if (list) {
  const tabs = [...list.querySelectorAll<HTMLButtonElement>('[role="tab"]')];
  const select = (tab: HTMLButtonElement, focus = false) => {
    for (const t of tabs) {
      const on = t === tab;
      t.setAttribute('aria-selected', String(on));
      t.tabIndex = on ? 0 : -1;
      document.getElementById(t.getAttribute('aria-controls')!)!.hidden = !on;
    }
    if (focus) tab.focus();
  };
  tabs.forEach((t) => t.addEventListener('click', () => select(t)));
  list.addEventListener('keydown', (e) => {
    const i = tabs.indexOf(document.activeElement as HTMLButtonElement);
    if (i < 0) return;
    const next = e.key === 'ArrowRight' || e.key === 'ArrowDown' ? tabs[(i + 1) % tabs.length]
      : e.key === 'ArrowLeft' || e.key === 'ArrowUp' ? tabs[(i - 1 + tabs.length) % tabs.length]
      : e.key === 'Home' ? tabs[0] : e.key === 'End' ? tabs[tabs.length - 1] : null;
    if (next) { e.preventDefault(); select(next, true); }
  });
  select(tabs[0]);
}
```
