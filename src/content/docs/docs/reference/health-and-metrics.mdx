## Health endpoints

Both are on the HTTP port (default `:8080`) and need no authentication.

| Endpoint | Purpose | Response |
|---|---|---|
| `GET /health/live` | **Liveness**: is the process alive? | `200 ok` (plain text, always) |
| `GET /health/ready` | **Readiness**: can the server serve traffic? | `200` or `503`, with JSON |

`/health/ready` checks the database and the scheduler:

```json
{
  "status": "healthy",
  "checks": {
    "database":  { "status": "ok", "latency_ms": 2 },
    "scheduler": { "status": "ok" }
  }
}
```

It returns `503` with `"status": "unhealthy"` when a check fails, for example when the database is
unreachable. The Docker Compose files and the Helm chart probe `/health/ready`, so the container is restarted
or taken out of rotation when the database is down.

## Prometheus metrics

`GET /metrics` serves Prometheus metrics on the HTTP port.

| Metric | Type | Labels | Description |
|---|---|---|---|
| `arkeep_jobs_total` | Counter | `status`, `job_type` | Jobs that reached a final state (`succeeded`, `failed`, `cancelled`) |
| `arkeep_job_duration_seconds` | Histogram | `job_type` | Job duration in seconds |
| `arkeep_agents_connected` | Gauge | | Agents holding an active gRPC connection |
| `arkeep_http_requests_total` | Counter | `method`, `route`, `status_code` | HTTP requests handled |
| `arkeep_http_request_duration_seconds` | Histogram | `method`, `route` | HTTP request latency in seconds |
| `go_*`, `process_*` | various | | Go runtime and process metrics |

```yaml title="prometheus.yml"
scrape_configs:
  - job_name: arkeep
    static_configs:
      - targets: ['arkeep-server:8080']
    scrape_interval: 15s
    # When ARKEEP_METRICS_TOKEN is set:
    authorization:
      credentials: <token>
```

## Restricting access

These endpoints expose no credentials, backup contents or user data, but they reveal operational details:
how many agents you run, how often jobs run, error rates.

- Set `ARKEEP_METRICS_TOKEN` to require a bearer token on `/metrics`.
- Or restrict the endpoints at your reverse proxy:

```nginx
location /metrics {
    allow 10.0.0.0/8;   # your internal network or Prometheus scraper
    deny all;
}
```

Without a reverse proxy, block port 8080 from untrusted networks with a firewall.
